# benchmarks/ — framework-agnostic task data

One folder per benchmark, each emitting `tasks.jsonl` in a **single uniform schema**
so any MAS harness (`camel/`, `autogen_gc/`) loads any benchmark the same way. These
are the **hard slices** chosen so the tasks actually exercise multiple agents with
internal loops (not trivially one-shot) — see the selection rationale in `../PLAN.md`.

| Benchmark | Dir | n | `answer_type` | `tool_profile` | Hard? / honesty | Source | Gated |
|---|---|---|---|---|---|---|---|
| **GAIA** | `gaia/` | **17** evaluated (of 26 L3; **9 vision/media excluded** → `EXCLUDED.md`) | `freeform` | `web_compute` | GAIA's hard slice: longest multi-source tool chains | `gaia-benchmark/GAIA` validation | **yes** |
| **GPQA-Diamond** | `gpqa_diamond/` | 198 | `mcq` | `none` | PhD-level, expert-validated → **honesty showcase** | `Idavidrein/gpqa` | **yes** |
| **MATH level-5** | `math_l5/` | 134 | `math` | `math` | hardest MATH tier; critic recompute has teeth | `HuggingFaceH4/MATH-500` (lvl 5) | no |
| **PopQA** | `popqa/` | 200 (long-tail) | `qa` | `none` | lowest-`s_pop` entities → parametric recall collapses → `wrong_confident` substrate for the honesty axis | `akariasai/PopQA` | no |
| **FEVER** | `fever/` | 201 (balanced) | `label` | `none` | 3-way claim verification; **NEI is native honesty** (no `abstained` bucket — see scoring) | `copenlu/fever_gold_evidence` | no |
| **PDDL** | `pddl/` | 23 (4 domains) | `pddl` | `pddl` | **interactive planning** (Blocks/Gripper/Ferry/Hanoi); belief-state testbed — `obs.literals` IS the board; scored on env goal-state | `pddlgym` | no |

## Record schema (one JSON object per line)
```json
{
  "id": "gpqad_007",
  "bench": "gpqa_diamond",
  "question": "<full prompt the agent sees, incl. A-D options for mcq>",
  "expected_answer": "C",
  "answer_type": "freeform | mcq | math | qa | label | pddl",
  "tool_profile": "none | math | web | web_compute | pddl",
  "meta": { "subdomain": "...", "level": 5, "...": "source bookkeeping" }
}
```
`answer_type` drives `camel/harness/scoring.py`: `freeform` (numeric-aware exact),
`mcq` (letter match), `math` (strip `\boxed`/`$`, numeric-aware), `qa` (EM/word-bounded
against a JSON alias list in `expected_answer`), `label` (FEVER 3-way; a model "unknown"
maps to NEI and is scored vs gold, so there is **no `abstained` bucket** for FEVER), and
`pddl` (no string match — outcome is read from the env's terminal goal-state via
`classify_pddl_outcome`; `expected_answer` is an unused placeholder). The `pddl`
`tool_profile` binds the stateful `pddl_observe/pddl_actions/pddl_step` tools to a
per-task `PddlEnv` (`camel/harness/pddl_env.py`).

## (Re)generating the data
`tasks.jsonl` is **git-ignored** (derived + reproducible; also keeps gated GPQA/GAIA
content out of git). Regenerate locally — all three need `HUGGINGFACE_TOKEN` in the
repo-root `.env` with *public-gated-repo* access. **GPQA** and **GAIA** are gated: accept
their terms once on the HF page (GPQA = click-through; **GAIA = manual access request,
approval not instant**). GAIA prep also needs `pyarrow` + `openpyxl` + `pypdf` (parquet
metadata; doc attachments are staged into `gaia/files/` and read via the `read_file` tool;
web PDFs are extracted by `fetch_url`). GAIA splits L3 into an evaluated `tasks.jsonl` and a
vision/media `excluded_vision.jsonl` (see `gaia/EXCLUDED.md`):
```
conda run -n autogen_gc python benchmarks/gaia/prep.py
conda run -n autogen_gc python benchmarks/gpqa_diamond/prep.py
conda run -n autogen_gc python benchmarks/math_l5/prep.py
conda run -n autogen_gc python benchmarks/popqa/prep.py   # POPQA_N=N for a bigger long-tail slice
conda run -n autogen_gc python benchmarks/fever/prep.py   # FEVER_PER_CLASS=N per label
conda run -n camel_pddl  python benchmarks/pddl/prep.py   # NEEDS pddlgym -> camel_pddl env
```
GPQA options are shuffled **deterministically** (seeded by Record ID), so regeneration
is stable. The HF token is never written into `tasks.jsonl`. **PopQA/FEVER are public**
(no gating). **PDDL** is generated by introspecting `pddlgym` (no HF), and because
pddlgym needs `gym 0.26` it lives in a dedicated **`camel_pddl`** env
(`conda create -n camel_pddl --clone autogen_gc && conda run -n camel_pddl python -m pip install pddlgym`).

## Running through the harness
```
# smoke a few; full set with --all
conda run -n autogen_gc python camel/harness/run_task.py --tasks gpqa_diamond --limit 2
conda run -n autogen_gc python camel/harness/run_task.py --tasks math_l5 --all
conda run -n autogen_gc python camel/harness/run_task.py --tasks gaia gaia_50f58759   # by id
conda run -n autogen_gc python camel/harness/run_task.py --tasks popqa --limit 3
conda run -n autogen_gc python camel/harness/run_task.py --tasks fever --limit 3
conda run -n camel_pddl  python camel/harness/run_task.py --tasks pddl  --limit 3     # PDDL -> camel_pddl
```
`--tasks` resolves a bare benchmark name to `benchmarks/<name>/tasks.jsonl`. **PDDL tasks
must run in `camel_pddl`** (the only env with pddlgym); it's a superset clone of
`autogen_gc`, so it can run the other benchmarks too if you prefer one env.
